3. Fix operational defects immediately in a new tested version. For discretionary strategy tuning, change one main idea per sport per checkpoint and keep at most one new challenger per sport active. Do not search many parameter combinations and present only the winner.
4. Create new source files/module names, a new frozen manifest and a new output/ledger directory. Do not edit source files referenced by running baseline/capture fingerprints or merely replace their hashes. Ensure the candidate's imports reference the intended candidate implementation and preserve recovery launchers for each version.
